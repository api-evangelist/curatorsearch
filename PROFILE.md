# CuratorSearch

An independent, daily-refreshed record of museum/gallery/curatorial vacancies and advertised salaries, aggregated from 400+ institutions' careers pages. Exposes a keyless REST/JSON API, an OpenAPI 3.1 contract, a hosted MCP server, llms.txt, open datasets (CC BY 4.0, with DOI), and RSS.

- **Provider:** https://curatorsearch.com
- **Documentation:** https://curatorsearch.com/developers
- **Base URL:** https://curatorsearch.com
- **Tags:** museum jobs, curatorial, cultural heritage, job board, salaries, pay transparency, open data, dataset, MCP, agent-native, RSS
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 97/100

## APIs

- **CuratorSearch Jobs API** — Keyless, read-only REST/JSON API for searching museum/curatorial vacancies and retrieving individual listings, plus the full advertised-salary archive. Documented via a live OpenAPI 3.1 contract. (`https://curatorsearch.com`)

> OpenAPI 3.1 (/openapi.json), /llms.txt, /feed.xml, and /data/curatorial-salaries.json were all confirmed live via fetch. The hosted MCP server at https://curatorsearch.com/mcp is a stateless Streamable HTTP (POST) endpoint declared in apis.json and the portal (four read-only tools: search_jobs, get_job, institution_jobs, salary_transparency); it is POST-only so could not be dereferenced via GET but is a real hosted endpoint. /api/jobs is documented in OpenAPI but was blocked by the fetch tool's URL policy. Also available: llms-full.txt (declared), open datasets (CSV/JSON, DOI 10.5281/zenodo.22544232), RSS feed, and an embeddable badge. No GraphQL, AsyncAPI, Postman collection, or packaged agent skills were found. A private keyed partner feed is available on request.
