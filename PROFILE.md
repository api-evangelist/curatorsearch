# CuratorSearch

Live museum, gallery and curatorial job listings gathered daily from 400+ institutions' own career pages, plus a permanently archived advertised-salary dataset. Exposes a public REST/JSON API, a hosted MCP server, and llms.txt for both programs and AI assistants.

- **Provider:** https://curatorsearch.com
- **Documentation:** https://curatorsearch.com/developers
- **Base URL:** https://curatorsearch.com

## APIs

- **CuratorSearch API** — REST/JSON API over the live curatorial jobs board and salary archive: searchJobs (GET /api/jobs), getJob (GET /api/jobs/{slug}), and salaryArchive (GET /data/curatorial-salaries.json). Also a hosted MCP server with four read-only tools and llms.txt/llms-full.txt. No key required for public read access. (`https://curatorsearch.com`)

> Provider exposes a confirmed public REST/JSON API with OpenAPI 3.1.0 contract, a hosted MCP server (Streamable HTTP, POST, four read-only tools: search_jobs, get_job, institution_jobs, salary_transparency; no key needed) at https://curatorsearch.com/mcp, and both llms.txt and llms-full.txt. All read access is keyless; a private keyed partner feed exists on request via support@curatorsearch.com for bulk/full-feed use. RSS feed at https://curatorsearch.com/feed.xml. Datasets (Curatorial Pay Archive, Pay Transparency Index, Hiring Index) available as CSV/JSON under CC BY 4.0 (DOI 10.5281/zenodo.22544232). No AsyncAPI, GraphQL, or Postman collection found.
